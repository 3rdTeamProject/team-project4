# 보관 중인 작물 이미지

배추(`cabbage`), 양파(`onion`), 수박(`watermelon`), 파(`green-onion`)의 성장 단계별 임시 PNG 이미지입니다.

- 파일명: `<crop>-<stage>.png` (`stage` 1~4)
- 현재 텃밭 화면과 성장 이미지 미리보기에서는 사용하지 않습니다.
- 정식 작물로 추가할 때 `frontend/public/garden/assets/crops/`로 옮기고 `crop-art.js`, `features.js`, 성장 미리보기 목록 및 이미지 표시 범위를 다시 연결하세요.
