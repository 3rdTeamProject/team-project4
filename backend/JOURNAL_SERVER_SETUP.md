# 재배일지 원본 사진 저장

원본 사진은 `DATABASE_URL`이 가리키는 PostgreSQL의 `garden_original_photos.photo_data` (`BYTEA`)에 저장한다. 별도의 Supabase Storage 키나 버킷 설정은 필요하지 않다. 서버 시작 시 기존 `garden_original_photos` 테이블에 `photo_data` 컬럼이 없으면 추가한다.

브라우저는 JPG, PNG, WEBP 원본을 최대 10MB까지 받는다. 사진을 자르지 않고 긴 변을 최대 2000px로 줄여 JPEG 품질 0.85로 변환한 뒤 업로드한다. API는 저장용 JPEG의 크기와 최대 2000px 규격을 다시 검사한다. 다운로드되는 파일은 이 변환본이며 업로드 원본으로 되돌릴 수 없다.

사진 조회·다운로드는 로그인한 소유자에게만 허용한다. 지난 재배를 서버에서 삭제하면 연결된 사진 행도 같은 데이터베이스 트랜잭션에서 삭제한다.

기존 버전의 Storage에 이미 저장된 사진이 있다면, `photo_data`에 자동으로 복사되지 않는다. 그런 사진을 옮기려면 별도 마이그레이션이 필요하다. 데이터베이스 백업에는 이제 원본 사진 바이트도 포함되므로 백업 용량과 보관 정책을 함께 확인한다.
